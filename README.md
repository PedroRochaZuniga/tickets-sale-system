# tickets-sale-system
# 🎟️ Ticket Sales Management System

## 🇺🇸 English

### 📌 About

This project was originally developed in **2024**.

It is a simple and intuitive system for managing ticket sales. The program allows the user to:

* Register sales
* View a full sales report
* Analyze data such as total revenue, tickets sold, and distribution by user type and payment method

⚠️ **Note:**
This project reflects my knowledge at the time (2024). The code was not modified after its original development and is being published for portfolio purposes.

---

### ⚙️ Features

* Sales registration system
* Daily revenue calculation
* Total tickets sold
* Sales breakdown by:

  * User type (student, staff, external, etc.)
  * Payment method (PIX, card, cash)
* Text-based bar charts for visualization

---

### 🧠 Concepts Used

* Object-Oriented Programming (OOP)
* Enums (`Enum`)
* Data classes (`@dataclass`)
* Lists and data aggregation
* User input handling
* Basic data visualization (console)

---

### ▶️ How to Run

Make sure you have Python installed.

```bash
python main.py
```
